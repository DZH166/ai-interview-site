# 阶段:追问进入模拟面试(二跳练习)(2026-09-13,基线见 git log 阶段1 提交)

## 为什么做

模拟面试此前只考主题:写回答 → 对照 → 复盘。但面试的真实压力在**追问**——
面试官会顺着你的回答往下挖。题库里每题 2-3 条 followups、Pi Agent 90 条嵌套追问,
此前只能在完整解析里「看」,没有进入练习循环。

## 实现

| 落点 | 内容 |
| --- | --- |
| `app/js/views-practice.js` | 对照参考要点后出现「追问二跳」区:每个追问同样**先写后看**(参考默认折叠);回答进会话草稿(`answers[qid].fu[i] = {self, revealed}`),随会话落盘,刷新自动恢复;`captureInput` 同时同步追问框(切题/结束前不丢输入) |
| `finish()` | 轮次记录的题目条目新增 `followups` 字段——**只保留真实写过的**(有回答或已对照),没碰过的不占位 |
| `app/js/express.js` | 表达卡新增「追问练习」一节:写过的带原文;对照过但没写的如实标注「当时没有写下回答」,不冒充;旧格式轮次(无 followups 字段)不受影响 |

## 测试

- `tests/express-card-test.js` 扩至 47 条(新 7 条):追问进卡、没碰过的不占位、
  对照过没写的如实标注、旧格式轮次兼容。
- `tests/browser/followup.js`(新,12 条):未对照前无追问区 → 对照后出现 → 先写后看 →
  草稿进 Store → 刷新恢复(回答与揭示状态) → 完成轮次带追问 → 表达卡含追问原文 → 全程无 JS 异常。
- 全量回归:Node 290 / Python 71+ / 浏览器 205 条全绿;构建可复现(两次运行逐字节一致);
  CI browser job 增至 8 步。

## 诚实边界

- 追问回答不改变题目状态、不参与 SRS 排期(它不是对该题的完整复盘信号,不假装是);
- 追问参考在「对照」后保持展示,与主题回答的先写后看一致,不做二次隐藏。

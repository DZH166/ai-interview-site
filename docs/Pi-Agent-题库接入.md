## 数据与界面

| 来源字段 | 工作台位置 |
|---|---|
| title / question | 标题 / 始终可见的完整题干 |
| pitched_answer | 直接答案、面试表达 |
| why_it_matters / terms | 大白话解释中的考察价值与术语 |
| explanation / fact_scope / version_notes | 原理拆解与版本边界 |
| practice | 具体例子、理解检查；明确标记尚未执行 |
| follow_ups / misconceptions | 常见追问 / 常见误区 |
| rubric | 面试表达与理解检查中的评分标准 |
| sources | 出处区固定提交链接与定位符号 |
| 原始完整对象 | metadata.pi_agent.original |

学习页、浏览详情、自测与表达卡支持可选 `prompt` 字段。参考答案继续默认隐藏；场景题不再仅剩一个短标题。完整题干也参与搜索。无 prompt 的原题保持原交互。

## 来源与幂等维护

固定 Pi **v0.85.1**,提交 `d981de1229ef899957bbe968bc8dcda02a21f477`。本次执行源资料的只读校验与自检,确认30题、90追问、3组、内容哈希、生成资料一致,以及51个引用源码文件在该提交存在。没有运行30项建议练习、Pi完整测试套件或真实模型评分。核查状态保留为版本相关/部分核查,不升级成新一轮全量事实认证。

仓库中的 `data/imports/pi-agent/` 保存原始题库、manifest、术语与来源范围；没有复制整个本地目录或ZIP。正常维护命令：

```text
node tools/import-pi-agent.js          # 只预演
node tools/import-pi-agent.js --write  # 应用受管内容
node tools/import-pi-agent.js --check  # 检查生成一致性
python tools/build.py                 # 更新应用数据及缓存版本
```

题号使用 PI 稳定编号,外部标识为 `pi-agent-interview-30:PI-xxx`。原生正文被手工修改、编号冲突或分类定义发生冲突时,适配器拒绝整批写入,保留现有内容。它不连接、清空或初始化 localStorage。

回滚时仅撤销本批次内容、分类与配套渲染变更；个人学习数据继续保留。如果已有 PI 作答,应先导出备份并保留其ID映射,避免回滚后历史暂时没有对应题目。

# 混合题型与简历练习修复

基于 `48830f5`，开发分支 `codex/dev`。本轮修复 2026-09-20 实测发现的练习流程问题，题库仍为 3900 题、20 专题。

## 修复后的行为

1. 选择题的答案和官方解析一起隐藏、一起揭示。学习页和浏览详情共用这个行为；去掉会提前泄露答案的第二份默认展开解析，保留只存在于 plain 的补充解析。
2. 模拟面试显示选择题选项和单选/多选标记，仍通过原有文本框写答案和理由并自评。format、options、qtype 随作答快照保存；刷新及题库更新后使用原始选项。Markdown 和 HTML 表达卡也带选项。没有选项的旧快照保留原回答并提示题面不完整，不把当前选项冒充历史选项。
3. 首批和后续批次共用列表项渲染，加载第二批后可以实际勾选并批量更新。回归用例同时检查未勾选题不被改动。
4. 简历题目一题一行，桌面分列显示题号、题目、状态，窄屏题目换到独立行。同组重复题号只显示一次；总题数与掌握进度按唯一题号统计。
5. 简历页明确区分 158 道独立题目与 195 条配置关联，以及已掌握、实际练过、待复习。待复习不计入已掌握；跨项目关联保留。
6. 修正开放问答答案切换的按钮文案，不再变成“正确答案”；模拟练习不显示缺失的空口述区块。

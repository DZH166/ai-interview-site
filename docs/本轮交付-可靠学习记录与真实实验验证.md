### 项目C 的职责分离(重建的核心)

| 层 | 谁来判定 | 依据 |
| --- | --- | --- |
| ① 库里没有 | **仅评测侧** `coverage_oracle`(人工标注) | 运行侧无权下此结论;拒答文案必须留悬置 |
| ② 检索没捞到 | 运行侧 `retrieve` | 零召回 / 强命中被裁掉 / 最高分不达标 |
| ③ 证据被预算截断 | 运行侧 `diagnose` | `truncated` 且存在被丢弃的强命中 |
| ④ 生成没守证据 | 运行侧 `validate(answer_text, hits)` | 按回答文本判定 |

`EVAL` 评测集只放「标注 + 期望」,不含逐题阈值;未标注查询会明确报错而不是猜。

## 4. 全链验收(新增)

`tests/browser/e2e-acceptance.js` —— **从空存储开始**,走完整用户旅程:

4. 用自己的笔记搜回自己,两次:正式深链 `#/search/<词>` 与兼容写法 `#/search?q=<词>`;

7. **导出 → 清空 → 导入往返**:导出文件含笔记 → 清空后本地确无 → 导入后笔记、专项尝试都被完整还原;
8. 导入后检索索引已重建,能重新搜到笔记;
9. 整条链路无 JS 异常。

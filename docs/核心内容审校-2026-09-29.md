## 主要修订

- **协议与 Agent**：AGQ-0030 固定 MCP 2025-11-25 的 stdio / Streamable HTTP；区分模型请求、宿主执行、授权和业务验收。AG-003/017/031/036/053 分别清理超时必重试、并发错误聚合、固定压缩水位、RAG 与记忆硬分界及延迟优化保证。AG-059/061 同步修正直观解释中的强制组合顺序和反向漏召回指标。LC-003 说明恢复会重跑节点，幂等键须结合接收方实际实现。
- **RAG**：RGQ-0026 固定 E5-large-v2 的 query:/passage: 输入合同，不推广到所有嵌入模型。区分 RRF 排名融合与分数相加，稀疏/密集互补与必然收益，重排失败与候选漏召回。RG-011/012/047/057 明确引用存在不等于证据支持，低分不等于无答案，流式校验不能撤回已读错误。MRL 前缀训练、PCA 投影和向量量化分别讲解，不把后处理量化说成必须由嵌入模型专门训练。
- **Python**：修正 TypedDict 构造与运行时类型检查、frozen 的浅层限制、装饰器不一定返回新函数、Depends 不是装饰器、gather 默认异常传播与 TaskGroup 取消的区别、提前 break 的异步生成器清理、ContextVar 的浅层传播和权限边界。区分 BackgroundTasks、持久队列、调度触发与业务成功；给定时/后台工作补故障诊断而非虚构运行结果。
- **Prompt 与基础**：去掉无依据的固定温度、示例数量、收益阈值和“长推理即可审计”保证。说明角色标签不能赋予资格、知识或权限；Few-shot 顺序和模型能力需具体评测。YaRN 按 v2 的频率分段处理及注意力缩放解释，不混同生成采样温度；区分注意力中间矩阵与 KV Cache 的增长。
- **可执行性**：IVL-0001 按 Transformers 4.50.0 补 tokenization → Dataset.map → data collator → Trainer 接线，并注明需要数据、模型和环境，不将静态审校写成训练完成。

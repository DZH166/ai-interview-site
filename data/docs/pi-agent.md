# Pi 面试术语速查

## LLM · 大语言模型

接收上下文并生成文本或结构化调用的模型。

相关题：[PI-001](#/study/PI-001)

## Agent · 智能体

通过模型决策、工具执行和反馈循环推进任务的系统。

相关题：[PI-001](#/study/PI-001)

## Harness · 运行框架

把模型、工具、消息与运行控制连接起来的承载程序。

相关题：[PI-001](#/study/PI-001)

## Workflow · 工作流

主要执行顺序和分支由开发者预先规定的流程。

相关题：[PI-001](#/study/PI-001)

## Provider · 模型提供方

拥有模型目录、鉴权和调用方式的模型服务适配对象。

相关题：[PI-002](#/study/PI-002)、[PI-009](#/study/PI-009)

## SDK · 软件开发工具包

供其他程序直接调用的接口与代码库。

## TUI · 终端用户界面

相关题：[PI-002](#/study/PI-002)

## Dependency Injection · 依赖注入

把模型调用等依赖从外部传给程序，方便替换和测试。

相关题：[PI-002](#/study/PI-002)

## Run · 一次运行

相关题：[PI-003](#/study/PI-003)

## Turn · 一轮

一次助手响应及它触发的工具执行和结果。

相关题：[PI-003](#/study/PI-003)

## Event · 事件

相关题：[PI-003](#/study/PI-003)

## Tool Result · 工具结果消息

## Streaming · 流式返回

相关题：[PI-004](#/study/PI-004)

## Partial JSON · 部分JSON

相关题：[PI-004](#/study/PI-004)

## stopReason · 停止原因

## Side Effect · 副作用

## Graceful Stop · 优雅停止

允许当前工作单元完成，再阻止后续单元开始。

相关题：[PI-006](#/study/PI-006)

## Abort · 取消

通知进行中的操作尽快结束，而非自动撤销副作用。

相关题：[PI-006](#/study/PI-006)

## Budget · 预算

## Hook · 钩子

相关题：[PI-007](#/study/PI-007)

## details · 结构化详情

## Parallel · 并行执行

相关题：[PI-008](#/study/PI-008)

## Sequential · 串行执行

相关题：[PI-025](#/study/PI-025)

## Faux Provider · 假模型提供方

按预先写好的响应模拟模型接口，便于低成本测试。

相关题：[PI-026](#/study/PI-026)

## Agent Eval · 智能体行为评测

用固定任务与评分规则衡量真实 Agent 是否完成目标。

相关题：[PI-026](#/study/PI-026)

## Fixture · 固定测试数据

测试开始前准备好的输入和环境，便于重复比较。

相关题：[PI-026](#/study/PI-026)

## LLM-as-a-judge · 由模型担任评审

让另一个模型按评分规则评价答案，需要校准而非盲信。

相关题：[PI-026](#/study/PI-026)

## RAG · 检索增强生成

先从外部资料中查找相关内容，再让模型依据这些内容回答。

相关题：[PI-027](#/study/PI-027)

## ACL · 访问控制列表

规定哪些用户可以查看或操作哪些资源的权限记录。

相关题：[PI-027](#/study/PI-027)

## Grounding · 答案依据绑定

把回答中的具体论断关联到真实可检查的证据。

相关题：[PI-027](#/study/PI-027)

## Citation · 引用

指明结论所依据的资料位置，引用存在不代表结论正确。

相关题：[PI-027](#/study/PI-027)

## Delegation · 任务委派

主 Agent 把边界明确的子任务交给其他 Agent 执行。

相关题：[PI-028](#/study/PI-028)

## Context Isolation · 上下文隔离

各 Agent 拥有自己的模型输入历史，不自动共享全部对话。

相关题：[PI-028](#/study/PI-028)

## Cancellation Propagation · 取消传播

父任务取消时把终止信号继续传给全部下游工作。

相关题：[PI-028](#/study/PI-028)

## Durable Execution · 持久执行

进程退出后仍保存执行位置，使后续进程能按规则继续。

相关题：[PI-029](#/study/PI-029)

## Lane · 执行通道

共享会话历史中的独立工作路径，带有自己的配置、队列和操作。

相关题：[PI-029](#/study/PI-029)

## Replay · 重放

故障恢复时再次执行之前可能已经执行过的步骤。

相关题：[PI-029](#/study/PI-029)

## Reducer · 状态归约函数

按新事件更新已有状态的函数，本题特指展示快照更新。

相关题：[PI-029](#/study/PI-029)

## Exactly-once · 恰好一次

业务效果只发生一次；仅有本地持久记录并不能保证外部服务满足。

相关题：[PI-029](#/study/PI-029)

## Version Contract · 版本契约

某个确定版本承诺的接口形状和行为边界。

相关题：[PI-030](#/study/PI-030)

## Regression Test · 回归测试

修改或升级后验证原先需要的行为仍然成立。

相关题：[PI-030](#/study/PI-030)

## Source-only · 仅源码模式可用

能力存在于仓库开发环境，标准发布包不提供同等可用入口。

相关题：[PI-030](#/study/PI-030)

## Lockfile · 依赖锁文件

记录安装所用依赖的确定版本，方便复现环境。

相关题：[PI-030](#/study/PI-030)

## Rollback · 降级回退

新版本有问题时恢复到已验证版本和相容的数据状态。

相关题：[PI-030](#/study/PI-030)

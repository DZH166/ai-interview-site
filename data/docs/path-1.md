以下路线按"课业之余每周 6~10 小时"设计,可压缩可拉长,但**每个节点都要动手输出**(写答案、做自测),只读不练记不住。

## 第 1~2 周:基础与原理(建立地基)

- 阅读:[Python 后端学习地图](#/docs/doc-python-1)、[AI 基础原理](#/docs/doc-fund-1);
- 题目:PY-001 ~ PY-004、FD-001、FD-002;
- 节点:能口头讲清生成器的执行模型、asyncio 与线程的区别、注意力的 Q/K/V 直觉;
- 动手:用 FastAPI 写一个带 Pydantic 校验的最小接口(对照 [PY-004](#/study/PY-004))。

## 第 3 周:大模型调用层

- 阅读:[大模型调用与提示词](#/docs/doc-llm-1);
- 题目:LP-001 ~ LP-004;
- 节点:能画出"上下文窗口预算表"、说出结构化输出三档的区别与服务端闭环;
- 动手:调一次真实/模拟 LLM API,实现结构化输出+校验重试(对照 [LP-003](#/study/LP-003))。

## 第 4~5 周:RAG(重心)

- 阅读:[RAG 全景](#/docs/doc-rag-1);
- 题目:RG-001 ~ RG-004;
- 节点:能白板画出两条管线图 + 故障四分类;
- 动手:用 10~20 个文档做一个最小 RAG(向量检索即可),故意问几个"答错"的问题,按 [RG-004](#/study/RG-004) 的方法定位。

## 第 5~6 周:Agent 与工程

- 阅读:[Agent 与工具调用](#/docs/doc-agent-1)、[工程实践](#/docs/doc-eng-1);
- 题目:AG-001 ~ AG-004、EN-001、EN-002;
- 节点:能讲清工具调用五步循环、Agent 四层护栏、缓存分层;
- 动手:给第 3 周的调用层加一个工具(如查询函数),实现完整的调用循环。

## 面试前一周

1. 只刷"待复习 + 还不熟"状态的题目;
2. 自测模式:随机 10 题/轮,先写后看,连续两轮全过即可;
3. 把自己项目的"故事线"按 EN-002 的框架梳理一遍:需求 → 架构 → 遇到的问题 → 怎么定位与解决 → 数据结果(**示例项目请如实标注是练手项目,不虚构指标**);
4. 通读[进阶专题说明](#/docs/doc-advanced-0),确认自己没有把时间错配到低频考点上。

## 状态管理建议

每学完一题就手动标状态:讲不顺 → 还不熟;能讲清 → 基本掌握;过两周还能讲清 → 保持;面试前把"待复习"清空。
